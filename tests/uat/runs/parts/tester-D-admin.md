## Defects

Severity is a tester estimate. Repro steps assume a seeded local instance.

1. **Cross-tenant read/write through admin URLs** (Critical, P0). Cases: UAT-PLAT-008 (also UAT-RES-018 step 4/6 area, UAT-ADM-008 step 5). In cloud mode, tenant B admin opens `/admin/establishments/1/edit`, `/admin/properties/1/edit`, `/admin/users/4/edit` of tenant `default` (200, real data), saves `PUT /admin/properties/1`, and `PUT`/`DELETE /admin/reviews/{id}` on a default-tenant review (row deleted). The reverse also works. `/admin/audit-logs` and `/admin/logs` show other tenants' data.
2. **Host can confirm payment on a reservation they do not manage** (High, P0). Case: UAT-RES-018. As host@ (E1 only) `POST /admin/reservations/{E2 reservation}/confirm-offline-payment` with a proof file -> 302, reservation confirmed, `paid` attempt and receipt created. `ReceiptController::confirmOfflinePayment` has no ownership check.
3. **Stored XSS on the public property page via JSON-LD** (High). Case: UAT-PROP-002. Create a published property named `<script>alert(1)</script>` and open `/properties/{slug}`: the name is written raw inside `<script type="application/ld+json">`, so `</script>` closes the block and the description's `<script>alert(1)</script>` becomes markup. In the same block, the `@context` key is compiled by Blade as the `@context` directive and leaks PHP text (resources/views/properties/show.blade.php ~l.25).
4. **Seasonal price rules are never applied** (High). Case: UAT-PROP-012. Add a 45000 rule for T+30..T+36 on a 30000 property and book T+31..T+34: the subtotal is 90000 (base rate). PricingCalculator ignores `rate_rules`.
5. **Admin reservation edit drops booked add-ons** (High). Case: UAT-RES-005. Book with an add-on (line "Option: ..."), then save the reservation unchanged in `/admin/reservations/{id}/edit`: the add-on line disappears and the total drops (86250 -> 69000).
6. **Reopening a cancelled reservation creates a double booking** (High, PO to confirm). Case: UAT-RES-010. Cancel R5, book R6 on the same dates, set R5 back to confirmed: accepted, two active overlapping reservations.
7. **Message notification e-mails always fail** (High). Case: UAT-MAIL-006. Any staff/customer message -> `message_received` row ends `failed` with "htmlspecialchars(): ... Illuminate\Mail\Message given (View: resources/views/emails/message-received.blade.php)" (the template uses the reserved `$message` variable).
8. **"Active" checkbox cannot be unticked** (Medium). Cases: UAT-ADM-002, UAT-ADM-006, UAT-EST-004. Untick "active" on a user or establishment edit form and save: success flash, value unchanged (no hidden 0 field; controllers keep the old value when the key is absent).
9. **Users list filters do not filter tenant users** (Medium). Case: UAT-ADM-008. `/admin/users?search=ZZZ-no-match` still lists all tenant staff; `?role=host` returns admins and concierges (ungrouped `orWhereNull`).
10. **Host can move a property into an establishment they do not manage** (Medium). Case: UAT-PROP-003. As host@ PUT own property with `establishment_id` of E2 -> saved, host then loses access.
11. **Admin-created reservations are linked to the staff user** (Medium). Case: UAT-RES-008. `reservations.user_id` = creating admin; opening the reservation creates no guest account and the "message customer" thread is attached to the admin.
12. **Interac security answer exposed** (Medium). Case: UAT-EST-010. The answer is stored in clear text, shown at checkout and copied into `audit_logs.details` visible on /admin/audit-logs.
13. **Duplicate names cause HTTP 500** (Medium). Cases: UAT-PROP-031 (amenity category with an existing English name), UAT-PLAT-003 (tenant with an existing name and blank slug). Unique slug constraint, no suffixing.
14. **Copy-improver timeout returns 500** (Medium). Case: UAT-PROP-018. Provider slower than 20 s: 20 s timeout x 2 tries exceeds PHP max_execution_time 30 s -> fatal error, 500 "Server Error" instead of the friendly 503. Provider error texts are English in the FR UI.
15. **Email amounts drop decimals** (Medium). Case: UAT-MAIL-004. EUR reservation 229.43 (subtotal 199.50) shows "200 EUR" / "229 EUR" in the payment-link mail.
16. **`property:sync-media` side effects** (Medium). Case: UAT-JOB-004. `--dry-run` writes all image variants and rebuilds DB rows; a corrupt image mid-run leaves the property with 0 images (no rollback).
17. **Settings page hides validation errors** (Medium). Case: UAT-ADM-009. Invalid site settings are rejected server-side but the redirected /admin/settings page shows no error. Sender/subject customisations are not used by reservation e-mails.
18. **Reservation-created e-mail has no stay dates** (Low-Medium). Case: UAT-MAIL-002.
19. **Generic 403/422 error pages hide the specific message** (Low). Cases: UAT-ADM-001, UAT-EST-005. "Administrator access is required." etc. appear only in JSON responses.
20. **Smaller UI gaps** (Low). UAT-PROP-001 (no amenity checklist on the create form), UAT-PROP-011 (public amenities not grouped by category), UAT-EST-011 (public establishment page shows no features), UAT-RES-007 (customer page does not show the customer's own remark; notes validation error not shown), UAT-EST-002 (slug required although the code derives it), seed data: E1 email "[TO BE PROVIDED]" blocks saving E1 (UAT-EST-004), property 1 video URL is relative and blocks re-saving (UAT-PROP-006).

## Blocked cases and why

- PO decision required: UAT-RES-011 (no refund/fee handling), UAT-RES-014 (no reject workflow), UAT-MAIL-008 (opt-out vs transactional mails), UAT-PLAT-012 (suspended tenant API policy), UAT-PLAT-019 (feedback triage process / audit privacy).
- Environment: UAT-RES-016 (receipt PDF download 500 because `barryvdh/laravel-dompdf` is missing from vendor/; needs `composer install` on the test host).
- Not executable within the rules/session: UAT-JOB-002 (needs hourly and 6-hourly boundaries and a 2-hour pause), UAT-JOB-003 (command rewrites the project .env).
